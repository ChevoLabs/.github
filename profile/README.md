# ChevoLabs

**ChevoLabs is a organization** that designs, builds and runs web applications and the cloud infrastructure behind them.

- 🌐 [chevolabs.com](https://chevolabs.com)  

### How we work

- **Secure by default.** Least-privilege cloud access, no long-lived keys in CI, secrets scanning on every change.
- **Everything as code.** Infrastructure, pipelines and configuration live in version control and go through review.
- **Fast and accessible.** Lightweight pages, accessibility checks in CI, performance budgets.
- **Small, reviewed changes.** Short-lived branches, pull requests and automated checks before anything ships.

### Working with us

Most of our repositories are private. To report a security issue, please follow our
[security policy](https://github.com/ChevoLabs/.github/blob/main/SECURITY.md). GitHub issues are not a support channel.
